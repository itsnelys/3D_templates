## Français

### Présentation
3D_templates est une bibliotheque d'assets, modeles et gabarits 3D. Le depot centralise des elements reutilisables pour prototypes, mods, mapping et projets visuels. Il sert de base de travail pour organiser et retrouver rapidement des ressources 3D.

### Fonctionnalités
- Categories d'assets pour objets, armes, vetements, vehicules et batiments.
- Ressources utilisables comme references internes ou bases de prototypage.
- Organisation par familles d'usage et types d'assets.
- Depot proprietaire reserve aux travaux autorises.

### Installation
Aucune installation specifique pour le moment.

### Utilisation
Utilise les dossiers d'assets comme bibliotheque interne et importe uniquement les fichiers necessaires dans les projets autorises.

### Structure du dépôt

```text

items weapons/
items_clothes/
mapping_buildings/
vehicle_airplane/
vehicle_cars/
vehicle_helico/
vehicle_ships/
README.md

```

## English

### Overview
3D_templates is a library of 3D assets, models and templates. The repository centralizes reusable elements for prototypes, mods, mapping and visual projects. It is used as a working base to organize and find 3D resources quickly.

### Features
- Asset categories for props, weapons, clothes, vehicles and buildings.
- Resources usable as internal references or prototyping bases.
- Organization by usage family and asset type.
- Proprietary repository restricted to authorized work.

### Installation
No specific installation required yet.

### Usage
Use the asset folders as an internal library and import only the required files into authorized projects.
